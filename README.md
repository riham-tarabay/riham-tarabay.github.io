# Riham Tarabay | AI & Data Solutions

Bilingual (English/Arabic) portfolio & services website — live at **https://riham-tarabay.github.io**

## Features

- **Single-file, zero dependencies** — the entire site (markup, styles, logic, translations) ships in one `index.html` with no frameworks, build step, or external requests.
- **Full English ⇄ Arabic toggle** with complete right-to-left (RTL) layout flip and persisted preference.
- **Dark / light mode** — follows system preference by default, manual toggle persisted in `localStorage`.
- **Consultation booking flow** — client-side validation, requests stored locally, success state generates a pre-filled email draft (works with zero backend).
- **Case studies** with a Problem → Approach → Result structure (RAG Knowledge Assistant, LangGraph Multi-Agent Workflow, CV/NLP Toolkit).
- **Accessibility**: WCAG-AA contrast, semantic landmarks, visible focus states, keyboard navigable, skip link.
- **SEO-ready**: meta description, Open Graph tags, single `h1`, semantic HTML.
